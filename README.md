## [🇰🇷 한국어]
### BarZidoROCK - 당신의 밤을 특별하게
홍대, 이태원부터 전국의 모든 펍과 라이브 공연장을 한 곳에서.  
밤의 문화를 즐기는 당신을 위한 올인원 플랫폼

### 🌃 앱 소개
BarZidoROCK은 매일 밤 색다른 경험을 찾는 당신을 위해 만들어졌습니다.  
홍대의 활기찬 클럽, 이태원의 감성적인 재즈바, 건대의 아늑한 펍까지...  
지금 당장 근처에서 열리는 라이브 공연을 확인하고 특별한 밤을 시작하세요.
> "단순한 지도 앱을 넘어, 당신의 밤을 풍요롭게 만드는 경험"

### ✨ 핵심 기능
#### 🗺️ **지도에서 한눈에 확인**
구글 지도 위에서 내 주변의 모든 공연장과 펍을 실시간으로 확인하세요.  
라이브 공연장은 🔴 네온핑크, 펍은 🔵 시안색 마커로 한눈에 구분할 수 있습니다.

#### 📍 **지역별 필터링으로 쉽게 찾기**
- 홍대, 이태원, 강남, 건대, 신촌 등 핫플레이스별 필터
- 라이브 공연장 / 펍 카테고리 분류
- 록, 재즈, 인디, 힙합 등 공연 장르 검색 지원

#### 🎤 **오늘의 라이브 공연 일정**
이번 주말 놓칠 수 없는 공연들을 홈에서 바로 확인!  
매진 임박 공연은 특별히 강조해서 보여드려요.

#### 💬 **상세 정보와 리뷰**
- 영업시간, 전화번호, 주소 한번에 확인
- 전화걸기 / 길찾기 바로 연결
- 실제 사용자들의 리뷰와 평점
- 내가 찜한 장소 모아보기

### 🎨 앱의 특징
#### 🌙 **감성적인 다크 테마**
밤에 사용하기 편안한 다크 모드로 네온사인 같은 시각적 경험을 선사합니다.

#### ⚡ **빠르고 부드러운 성능**
React로 개발되어 어떤 기기에서도 부드러운 스크롤과 빠른 로딩을 경험하세요.

#### ☁️ **실시간 데이터 동기화**
Firebase로 언제나 최신 공연 일정과 새로운 장소 정보를 받아보실 수 있습니다.

### 🛠 기술 스택
| 기술 | 사용 이유 |
|------|-----------|
| **React** | 웹 기반의 빠른 프로토타이핑과 넓은 개발 생태계 활용 |
| **Node.js (Express)** | API 서버 구축 및 외부 데이터 연동 |
| **Google Maps API** | 정확한 지도 서비스와 마커 기능 |
| **React Router** | 클라이언트 사이드 라우팅으로 매끄러운 페이지 전환 |

## [🇺🇸 English]
### BarZidoROCK - Make Your Night Special
From Hongdae, Itaewon to all pubs and live venues across Korea - all in one place.  
An all-in-one platform for those who enjoy nightlife culture.

### 🌃 About the App
BarZidoROCK was created for anyone looking for new experiences every night.  
From vibrant clubs in Hongdae, cozy jazz bars in Itaewon, to comfortable pubs in Konkuk University area...  
Check out live performances happening near you right now and start your special night.
> "More than just a map app - an experience that enriches your nights"

### ✨ Key Features
#### 🗺️ **At-a-glance on Map**
Check all venues and pubs near you in real-time on Google Maps.  
Live venues are marked with 🔴 neon pink, pubs with 🔵 cyan markers for easy identification.

#### 📍 **Easy Search with Regional Filters**
- Filters for popular areas: Hongdae, Itaewon, Gangnam, Konkuk, Sinchon
- Categorization: Live venue / Pub
- Genre search: Rock, Jazz, Indie, Hip-hop and more

#### 🎤 **Today's Live Performance Schedule**
Check out unmissable performances this weekend right from your home!  
Near-sold-out shows are specially highlighted.

#### 💬 **Details and Reviews**
- Check opening hours, phone number, address at a glance
- One-tap calling / Directions
- Real user reviews and ratings
- Save your favorite venues

### 🎨 App Features
#### 🌙 **Atmospheric Dark Theme**
Dark mode perfect for nighttime use, delivering a neon-like visual experience.

#### ⚡ **Fast and Smooth Performance**
Built with React for smooth scrolling and fast loading on any device.

#### ☁️ **Real-time Data Sync**
Always get the latest performance schedules and new venue information via Firebase.

### 🛠 Tech Stack
| Technology | Reason for Use |
|------------|----------------|
| **React** | Fast web prototyping and extensive development ecosystem |
| **Node.js (Express)** | API server construction and external data integration |
| **Google Maps API** | Accurate map services and marker functionality |
| **React Router** | Smooth page transitions with client-side routing |

### 🚀 Developer Setup
#### 1. Firebase Project Setup
```bash
# After creating a project in Firebase Console
npm install firebase
```
- Add Firebase config to environment variables file

#### 2. Google Maps API Key Setup
- Generate Maps SDK from Google Cloud Console
- Add API key to environment variables file

#### 3. Run the App
```bash
cd client
npm install
npm start
```

|--------|-------------|
| **Home** | Horizontal scroll of upcoming performances, filters, venue list |
| **Map** | View all venues on map, based on current location |
| **Detail** | Venue details, contact info, opening hours, upcoming performances |

BarZidoROCK专为每天追求新鲜体验的你而打造。

- 营业时间、电话、地址一键查看
